3. Năm đặc tính NIST

  1. On-demand self-service: Sinh viên tự tạo Codespace trên GitHub mà không cần người quản trị cấp máy.
  2. Broad network access: API có thể truy cập qua HTTPS từ trình duyệt trên điện thoại.
  3. Resource pooling: Codespace sử dụng hạ tầng điện toán được nhà cung cấp quản lý và chia sẻ.
  4. Rapid elasticity: GitHub cho phép thay đổi loại máy Codespace khi cần thêm tài nguyên. Chưa thực nghiệm thay đổi loại máy.
  5. Measured service: GitHub theo dõi mức sử dụng tính toán bằng core-giờ và lưu trữ bằng GB-tháng.

4. Kết luận

GitHub Codespaces cho phép tạo môi trường lập trình trên đám mây và chạy API mà không cần cài đặt Node.js trực tiếp trên máy cá nhân.

Bài thực hành minh họa năm đặc tính điện toán đám mây theo NIST, đồng thời tạo nền tảng mã nguồn cho các bài tiếp theo.
